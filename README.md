# abcd

abcd 虚拟现实工作室官网 — 虚拟现实开发 / 小游戏定制 / 工业数字孪生 / 高斯泼溅 / VR 培训。

纯静态 5 页站点（HTML + CSS + 原生 JS），零外部依赖，双击 `index.html` 即可预览。

## 页面结构

| 文件 | 说明 |
|------|------|
| index.html | 首页（Hero / 信任背书 / 优势 / 服务预览 / 评价 / CTA） |
| about.html | 关于我们（品牌故事 / 使命 / 差异化 / 时间线） |
| services.html | 服务（6 大服务 / 交付流程 / FAQ） |
| portfolio.html | 作品集（筛选栏 + 案例网格） |
| contact.html | 联系我们（表单 / 联系信息 / 地图） |

## 技术

- 响应式布局，移动端汉堡菜单
- SEO 基础优化（meta / 语义化 HTML / 图片 alt）
- 作品与服务卡片可携带 `?project=` 参数跳转联系页并自动预填留言
